# حمل العشرة

لعبة الصف الرابع: ضرب عدد من رقمين في رقم واحد مع إعادة التجميع (with regrouping).

مثال الدرس: 43 × 6 = 258.

## للطلبة

اللعبة بتتعمل من المتصفح. افتحي رابط النشر وابعثيه للطلبة، مش رابط جيتهب.

## تشغيل الكود

```bash
npm install
npm run dev
```

اللعبة على `http://127.0.0.1:8080`.
